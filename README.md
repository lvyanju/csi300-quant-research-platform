# 沪深300量化研究平台 · 公开演示版

Streamlit Community Cloud 入口文件：`public_app.py`。建议在创建应用时选择 Python 3.12。

公开版只展示已保存的研究快照、模型与策略、历史回测、预测记录和 DMA 复现过程。更新行情、训练、上传文件、重算回测和生成每日预测均被禁用。公开访客不会改写研究记录。完整研究版仍保存在本地第四次作业项目中。

## 部署步骤

1. 将此目录作为一个 GitHub 仓库发布。不要提交额外的 `.env`、密码、令牌或本机虚拟环境。
2. 在 [Streamlit Community Cloud](https://share.streamlit.io/) 使用 GitHub 登录并创建应用，选择该仓库及 `public_app.py`。
3. 选择 Python 3.12，等待依赖安装与应用启动，取得 `*.streamlit.app` 公网地址。
4. 用未登录浏览器打开该地址，检查总览、回测、遗传规划、趋势混合网络与 DMA 页签均可查看，操作按钮均不可点击。

注意：公开版行情快照截至 2026-10-30；这是课程研究展示，不是实时行情、投资建议或真实交易。IF 五分钟原口径尚无数据。趋势网络的结果来自已保存的本地训练，云端公开版不安装 PyTorch，也不执行训练。Streamlit Community Cloud 的文件系统不适合保存多人共享的长期交易记录，因此本版设为只读。
